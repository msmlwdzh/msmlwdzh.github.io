## 一杯咖啡的底色

调色板从深色翻转为明亮——拿铁奶白铺底，浓缩咖啡棕作字，经典咖啡棕为骨，再以宇宙靛蓝与星光金作点缀。

为什么不沿用深色？因为明亮更能传递咖啡馆的暖意。在奶白底上，一抹咖啡棕足以成为视觉锚点，而靛蓝与金则像窗外透进来的星光——克制，但让画面有了纵深。

- **Background** `#F4ECDC` — 拿铁奶白，明亮但不刺眼
- **Accent** `#6F4E37` — 经典咖啡棕，主点缀色
- **Accent Alt** `#4A3B7A` — 宇宙靛蓝，太空意象的对位
- **Gold** `#C9A24B` — 星光金，星辰与行星的高光

## 双字体的桥接

标题用 Fraunces——一支带光学尺寸的温暖衬线体，传递编辑感与手作温度；正文用 Space Grotesk——几何无衬线，名字里就带着 "Space"。

两套字体并非随意搭配：一个负责"咖啡"的暖，一个负责"太空"的冷与现代。它们在同一页面上对位，正是这个博客主题的缩影。

## 天体意象作装饰

装饰元素刻意做成"一语双关"——倾斜的轨道环，既是行星轨道，也像杯沿的咖啡渍；标题的句点被替换成一颗土星；底纹是散落的星辰。

```css
.orbit-ring {
  border: 1.5px solid var(--color-border);
  border-radius: 50%;
  transform: rotate(-22deg) scaleY(0.32);
}
```

在明亮底色上，这些意象以低透明度出现——有存在感，但不喧宾夺主。它们是主题的回声，不是主角。

## 总结

好的设计系统不是加法，是减法。每一处留白、每一个令牌、每一颗星辰，都是"刚好够用"的刻意选择——一杯咖啡的功夫，漫游代码与星辰。
