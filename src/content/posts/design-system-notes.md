## 色彩的克制

调色板刻意精简——一个深色背景、一个冷色高亮、一个暖色辅助，再加两个基于透明度的表面色。

为什么不更多？因为色彩越少，每一个颜色的存在感就越强。在深色背景上，哪怕一抹冰蓝都足以成为视觉锚点。

- **Background** `#0A0A0A` — 几乎纯黑，但不完全是
- **Accent** `#BBEEFF` — 冰冷而清透，像月光
- **Accent Alt** `#FF6B6B` — 温暖的对位，用于强调

## 动效的韵律

所有过渡使用 `cubic-bezier(0.44, 0, 0.56, 1)` — 一条源自 Framer 的平滑缓入缓出曲线。默认 300ms 时长，hover 状态即有反馈。

动效不是装饰，是交互的回声。

## 玻璃拟态

卡片使用半透明背景加微妙边框，在没有重阴影的情况下创造深度。

```css
.glass {
  background-color: rgba(255, 255, 255, 0.06);
  border: 1px solid rgba(255, 255, 255, 0.10);
  border-radius: 12px;
}
```

在深色背景上，这种处理让卡片像是漂浮在虚空中的光面板——有存在感，但不喧宾夺主。

## 总结

好的设计系统不是加法，是减法。每一处留白、每一个令牌、每一条动效曲线，都是"刚好够用"的刻意选择。
